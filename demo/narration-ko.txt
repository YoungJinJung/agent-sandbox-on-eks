60초 발표 멘트 · v20 장표 / v18 영상 편집본
전체 30분: 설명 24분 + 영상 1분 + Q&A 5분. 아래 진입·종료 멘트는 설명 시간에 포함합니다.
영상은 무음입니다. 자막과 함께 발표자가 설명합니다. 편집본 60초는 실제 처리 시간 측정값이 아닙니다.

19장 → 20장 · 재생 전 연결
“사용자 소유권 검증은 운영에서 추가할 부분입니다. 이제 현재 코드의 운영자 호출 경로를 60초 영상으로 보겠습니다. 대기 구간을 줄였고, 먼저 실제 Fargate 실행 여부를 확인합니다.”

00:00–00:18 · 환경 할당과 Fargate 확인
“먼저 환경 하나를 빌립니다. 이 Pod의 nodeName으로 실제 실행 Node를 조회합니다. Node 라벨은 fargate, Pod 스케줄러는 fargate-scheduler입니다. 이번 요청이 Fargate에서 실행됐음을 확인했습니다.”

00:18–00:28 · 도구 호출
“이제 출장 규정 예시 텍스트를 보냅니다. 공백 정리 도구이며, PDF 파싱이나 AI 요약은 연결하지 않았습니다.”

00:28–00:48 · 접근 범위
“같은 환경에서 접근 범위를 확인합니다. 허용한 HTTPS는 응답하지만, S3 목록 조회는 거부되고 비허용 HTTPS는 연결에 실패합니다. 실패 원인은 다음 장표에서 같은 Pod의 방화벽 로그와 대조하겠습니다.”

00:48–01:00 · 반환
“Claim을 반환하면 Sandbox와 Pod까지 삭제됩니다. Agent Sandbox는 환경의 수명을, AWS 구성은 접근 경계를 관리합니다.”

20장 → 21장 · 영상 종료 즉시 넘기고 연결
“Fargate 실행은 확인했습니다. 이제 연결 실패를 설명하고, 결과를 남긴 뒤 안전하게 끝내는 조건을 보겠습니다.”

21장 → 22장
“먼저 연결 실패의 원인부터 보죠.”
22장에서 연결 실패의 원인을 설명하고, 23장에서 같은 실행의 Pod IP·시각·SNI를 방화벽 로그와 대조합니다.
